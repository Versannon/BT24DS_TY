# Topic 4: Decision Trees and Support Vector Machines

## Decision Trees
Splitting criteria are used to partition data:
- **Gini Impurity**: $Gini(S) = 1 - \sum p_i^2$
- **Entropy**: $H(S) = -\sum p_i \log_2 p_i$

## Support Vector Machines (SVMs)
Finds the separating hyperplane that maximizes the margin. For non-linear data, SVMs use the **Kernel Trick** to project points into a higher-dimensional space where they become linearly separable.
