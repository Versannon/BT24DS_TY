# Topic 2: Regression Analysis

## Simple Linear Regression
Models a straight-line relationship:
$$y = w_1 x + w_0 + \epsilon$$
where $w_1$ is the slope, $w_0$ is the intercept, and $\epsilon$ is the error.

## Multiple Linear Regression
Models relationships with multiple features:
$$y = w_0 + w_1 x_1 + w_2 x_2 + \dots + w_n x_n + \epsilon$$

## Parameter Estimation
Solved using **Ordinary Least Squares (OLS)** analytically, or **Gradient Descent** iteratively (minimizing Mean Squared Error).
