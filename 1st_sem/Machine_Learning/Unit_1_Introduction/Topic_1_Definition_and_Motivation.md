# Topic 1: Definition and Motivation of Machine Learning

## What is Machine Learning?
Machine learning is a branch of artificial intelligence (AI) focused on building systems that learn from data, improve their performance over time, and make decisions or predictions without being explicitly programmed.

- **Arthur Samuel (1959)**: *"Field of study that gives computers the ability to learn without being explicitly programmed."*
- **Tom Mitchell (1997) Engineering Definition**: *"A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E."*

## Motivation
Traditional software development relies on manual rule creation:
`Input Data + Rules (Code) -> output`
This approach fails for complex tasks like natural language translation or computer vision, where the rules are too complicated to write. Machine learning flips the flow:
`Input Data + output Data -> Rules (Model)`
It automates the discovery of mappings, allowing computers to solve unstructured, complex problems at scale.
