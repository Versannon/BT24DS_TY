# Topic 1: Ensemble Learning Methods

- **Bagging (Bootstrap Aggregating)**: Fits multiple independent models on bootstrap samples of the training data and averages predictions. Reduces variance. *Example*: **Random Forest** (adds random feature selection).
- **Boosting**: Trains models sequentially, where each new model is weighted to fix errors made by previous models. Reduces bias. *Examples*: **AdaBoost**, **Gradient Boosting**, **XGBoost**.
