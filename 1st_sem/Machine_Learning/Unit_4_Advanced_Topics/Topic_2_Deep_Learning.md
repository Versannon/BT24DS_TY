# Topic 2: Deep Learning

- **Feedforward Neural Networks (MLP)**: Input layer, multiple hidden layers with weights/biases and activation functions, and output layer.
- **Convolutional Neural Networks (CNNs)**: Uses parameter-shared convolutional filters to capture spatial grid patterns (highly popular for images).
- **Recurrent Neural Networks (RNNs)**: Possesses cyclic connections allowing memory of sequence state over time steps (popular for NLP and time series).
