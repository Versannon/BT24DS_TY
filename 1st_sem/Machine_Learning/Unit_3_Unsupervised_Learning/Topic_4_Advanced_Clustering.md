# Topic 4: Advanced Clustering Techniques

- **Fuzzy C-Means**: Soft clustering where each point has a degree of membership in each cluster.
- **Gaussian Mixture Models (GMM)**: Probabilistic clustering modeled as a mixture of Gaussians, optimized using **Expectation-Maximization (EM)**.
- **Spectral Clustering**: Uses similarity graph eigenvalues to perform dimension reduction before clustering.
