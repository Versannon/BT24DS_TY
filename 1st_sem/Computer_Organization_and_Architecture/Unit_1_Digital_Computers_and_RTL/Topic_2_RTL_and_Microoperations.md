# Topic 2: Register Transfer Language (RTL) and Instruction Cycle

- **Register Transfer**: Copying values ($R2 \leftarrow R1$).
- **Bus Transfers**: Shared paths using Multiplexers.
- **Micro-operations**: Arithmetic, Logic, Shift (logical, circular, arithmetic sign-preserving).
- **Instruction Cycle**: Fetch -> Decode -> Read Effective Address -> Execute.
