# Topic 1: Data Sources and Collection Methods

## Understanding Data Types
Before we can analyze data, we need to know what form it takes. Data comes in many shapes and sizes, but it generally falls into three main categories:

### 1. Structured Data
This is the neatest and most organized type of data. It fits perfectly into rows and columns, just like a spreadsheet or an Excel file.
*   **Simple Example**: A list of employees where every row is a person, and the columns are "Name," "Age," and "Salary." Because it is highly organized, computers can search and analyze it very quickly. It is typically stored in SQL databases.

### 2. Semi-Structured Data
This data isn't perfectly organized into a grid, but it still has some tags or markers that separate different elements. It’s a middle ground between structured and unstructured.
*   **Simple Example**: Think of an email. It has specific fields like "To", "From", and "Subject" (which are structured), but the main body of the email is just a block of text (which is unstructured). Common formats for this are JSON or XML, often used when apps communicate with each other over the internet.

### 3. Unstructured Data
This is the messy, wild west of data. It has no predefined format or organization. The vast majority of data generated today is unstructured.
*   **Simple Example**: A PDF document, an audio recording of a customer service call, a YouTube video, or a long post on social media. It takes special tools and artificial intelligence to extract meaning from this type of data because you can't just plug it into a traditional spreadsheet.

## Data Collection Methods
Once we know what type of data we want, how do we get it?

### Manual Collection
This relies on human effort to gather the data. It is usually slower but can capture nuanced human opinions.
*   **Simple Example**: Standing outside a store and asking people to fill out a paper survey about their shopping experience.

### Automated Collection
This uses computers and software to gather data without human intervention. It is fast and can handle massive amounts of information.
*   **Simple Example**: Using a script to "scrape" (copy) pricing data from a competitor's website every hour, or using an API to automatically pull daily weather forecasts into your system.

### Real-Time Collection
This involves gathering data continuously, exactly as it happens. This is crucial for systems that need to react instantly.
*   **Simple Example**: Sensors on an assembly line in a factory that instantly alert a manager if a machine starts to overheat, or a GPS app tracking your exact location second-by-second while you drive.

## Summary
Understanding where your data comes from and what shape it takes is the critical first step before any analysis can begin. Whether it's a neat spreadsheet or a chaotic collection of videos, the right collection method ensures you have the raw material needed for Business Intelligence.
