# Descriptive Analytics Lab Exercises Guide (BTDS-302-L)

This document provides a guide to the laboratory exercises required for the Descriptive Analytics course. Key Python scripts are located in the adjacent `code_examples/` directories.

## Exercise Index

### Lab 1: Introduction to R and Python
- **Objective**: Set up coding environment and perform basic matrix operations.

### Lab 2: Data Collection and Importing Data
- **Objective**: Read datasets from CSV, JSON, and web sources into Pandas.

### Lab 3: Data Cleaning and Preparation
- **Objective**: Impute missing values and detect/remove outliers.
- **See Implementation**: [data_prep_and_eda.py](../Unit_2_Data_Collection_Preparation_EDA/code_examples/data_prep_and_eda.py)

### Lab 4: Exploratory Data Analysis (EDA)
- **Objective**: Standardize data, perform initial visual inspections.
- **See Implementation**: [data_prep_and_eda.py](../Unit_2_Data_Collection_Preparation_EDA/code_examples/data_prep_and_eda.py)

### Lab 5: Descriptive Statistics
- **Objective**: Compute mean, median, standard deviation, skewness, and kurtosis.
- **See Implementation**: [data_prep_and_eda.py](../Unit_2_Data_Collection_Preparation_EDA/code_examples/data_prep_and_eda.py)

### Lab 6: Probability Distributions
- **Objective**: Fit datasets to Normal or Binomial distributions and compute probabilities.

### Lab 7: Hypothesis Testing
- **Objective**: Run t-test and Chi-square test using SciPy.
- **See Implementation**: [statistics_and_mining.py](../Unit_3_Statistical_Summarization_and_Mining/code_examples/statistics_and_mining.py)

### Lab 8: Data Visualization with Excel
- **Objective**: Create basic dashboards using PivotTables and PivotCharts.

### Lab 9: Advanced Data Visualization with Python
- **Objective**: Plot heatmaps and dual-axis plots.
- **See Implementation**: [visualization_best_practices.py](../Unit_4_Data_Visualization_and_BI_Tools/code_examples/visualization_best_practices.py)

### Lab 10: Data Visualization with Tableau
- **Objective**: Connect Tableau to CSV data and design interactive dashboards.

### Lab 11: Data Visualization with Power BI
- **Objective**: Load data in Power BI Desktop and create visual dashboards with slicers.

### Lab 12: Clustering Analysis
- **Objective**: Group mock points using K-Means and evaluate with silhouette scores.

### Lab 13: Classification Analysis
- **Objective**: Fit Decision Trees and output a classification report.

### Lab 14: Association Rule Mining
- **Objective**: Run Apriori or Eclat to generate association rules for transactions.
- **See Implementation**: [statistics_and_mining.py](../Unit_3_Statistical_Summarization_and_Mining/code_examples/statistics_and_mining.py)

### Lab 15: Anomaly Detection
- **Objective**: Run Isolation Forest to filter outliers.
- **See Implementation**: [statistics_and_mining.py](../Unit_3_Statistical_Summarization_and_Mining/code_examples/statistics_and_mining.py)

### Lab 16 & 17: Reports & Dashboards in Tableau & Power BI
- **Objective**: Build comprehensive dashboards and publish/share reports.

### Lab 18: Data Storytelling with Visualizations
- **Objective**: Construct a presentation slide deck walking through a narrative arc.

### Lab 19 & 20: Real-World Data Analysis Projects
- **Objective**: Clean and analyze a public dataset (e.g. sales, Titanic, house pricing) and compile dashboards.

### Lab 21: Advanced Data Mining Techniques
- **Objective**: Apply multiple techniques (classification, regression, clustering) to a single complex dataset.

### Lab 22 & 23: BI Project Management & Evaluation
- **Objective**: Build a risk matrix and define KPI metrics to measure BI value.
