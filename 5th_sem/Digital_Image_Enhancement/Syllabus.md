# BTDS-305-MDM(C): DIGITAL IMAGE ENHANCEMENT SYLLABUS

## Course Objectives
1. Introduce fundamental concepts and techniques of digital image enhancement.
2. Enable students to process and enhance images for improved visual quality.
3. Familiarize students with spatial and frequency domain techniques.
4. Explore applications of image enhancement in medicine, remote sensing, and surveillance.
5. Develop problem-solving skills using modern image processing tools.

## Course Outcomes
After successful completion of the course, students will be able to:
- Explain principles of digital image enhancement.
- Apply spatial domain point processing and filtering.
- Implement frequency domain Fourier transform filtering.
- Apply edge detection and enhancement algorithms.
- Perform color image processing and color model conversions.
- Understand modern techniques (Wavelets, CLAHE, ML-based super-resolution).

---

## Unit-wise Syllabus

### UNIT-I: Introduction to Image Enhancement (03 Hours)
- Basics of image processing and enhancement, need for image enhancement.
- Image quality metrics: Mean Squared Error (MSE), Peak Signal-to-Noise Ratio (PSNR).
- Applications of image enhancement in medicine, remote sensing, and surveillance.

### UNIT-II: Spatial Domain Techniques (04 Hours)
- **Point Processing**: Contrast stretching, log transformation, power-law (gamma) correction, histogram equalization.
- **Image Smoothing**: Mean filter, median filter, Gaussian filter.
- **Image Sharpening**: Laplacian filter, high-boost filtering, unsharp masking.
- Adaptive enhancement techniques.

### UNIT-III: Frequency Domain Techniques (03 Hours)
- Fourier Transform for image processing (1D & 2D DFT/FFT).
- Frequency domain filters: Low-pass, high-pass, and band-pass (Ideal, Butterworth, Gaussian).
- Image smoothing and sharpening in the frequency domain.
- Discrete Cosine Transform (DCT) and its applications.

### UNIT-IV: Edge Detection and Enhancement (04 Hours)
- Basics of edge detection (first and second derivatives).
- Gradient-based methods: Sobel, Prewitt, and Canny edge detectors.
- Edge enhancement techniques.
- Applications of edge detection in object recognition.

### UNIT-V: Color Image Enhancement (04 Hours)
- Fundamentals of color models: RGB, CMY, HSV, YCbCr.
- Histogram equalization for color images (channel-by-channel vs. intensity channel only).
- Color balancing, tint correction, pseudo-color, and false-color processing.

### UNIT-VI: Modern Techniques and Applications (04 Hours)
- Wavelet-based image enhancement.
- Machine learning and deep learning for image enhancement (denoising autoencoders, super-resolution).
- Low-light image enhancement (CLAHE, Retinex) and underwater image processing.
- Case studies in real-world scenarios.
