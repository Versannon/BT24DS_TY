# BTDS-301-PCC: MACHINE LEARNING SYLLABUS

## Course Objectives
1. Understand the core principles and theories behind machine learning algorithms.
2. Gain practical experience in implementing and applying supervised and unsupervised learning techniques.
3. Explore advanced topics such as deep learning and reinforcement learning.
4. Learn how to evaluate and optimize machine learning models for performance and accuracy.
5. Develop critical thinking and problem-solving skills in the context of data-driven decision making.
6. Explore ethical considerations and societal implications of machine learning technologies.
7. Build a foundation for further study or career advancement in the field of machine learning and AI.

## Course Outcomes
After successful completion of the course, students will be able to:
- Explain foundational concepts in machine learning and the main paradigms.
- Select, implement, and tune supervised learning algorithms (regression & classification).
- Apply unsupervised learning techniques (clustering & dimensionality reduction).
- Apply ensemble learning methods, deep learning models, and reinforcement learning.
- Properly evaluate ML models using validation metrics and select optimal hyperparameters.
- Address issues of transfer learning, domain adaptation, adversarial attacks, and ethical fairness in AI.

## Unit-wise Syllabus

### UNIT-I: Introduction to Machine Learning (07 Hours)
- **Introduction and Motivation**: Definition, motivation, and historical context of machine learning.
- **Applications of ML**: Broad application areas, specific use cases, ethical and social implications.
- **Origin and Evolution**: Early foundations, statistical learning theory, rise of neural networks, contemporary trends.
- **Foundational Concepts**: Abstraction, knowledge representation, generalization, model complexity vs. interpretability.
- **Assessing Learning Success**: Evaluation metrics, cross-validation, model selection, hyperparameter tuning.
- **Steps to Apply ML**: Data preprocessing, model training, evaluation pipeline, deployment, and monitoring.
- **Overview of Methods**: Supervised learning, unsupervised learning, reinforcement learning.

### UNIT-II: Supervised Learning (08 Hours)
- **Introduction**: Overview, components, importance, and applications of supervised learning.
- **Regression**: Simple linear regression, multiple regression, non-linear regression.
- **Classification**: Decision Trees, Support Vector Machines (SVMs), Logistic Regression, performance evaluation.
- **Advanced Techniques**: Ensemble learning, Neural Networks for classification.

### UNIT-III: Unsupervised Learning (08 Hours)
- **Introduction**: Overview, importance, and applications of unsupervised learning.
- **Clustering Techniques**: Major clustering approaches (K-Means, Hierarchical, DBSCAN), evaluating cluster quality.
- **Dimensionality Reduction**: Linear (PCA) and non-linear techniques (t-SNE).
- **Advanced Clustering**: Soft vs. hard clustering, Fuzzy C-Means, Gaussian Mixture Models (GMM), Spectral clustering.

### UNIT-IV: Advanced Topics in Machine Learning (07 Hours)
- **Ensemble Learning**: Introduction, Bagging, Boosting.
- **Deep Learning**: Feedforward Neural Networks, CNNs, RNNs.
- **Reinforcement Learning**: Core concepts, Q-Learning, Deep Q-Networks (DQNs), Policy Gradient methods.
- **Model Interpretability**: Model-agnostic and model-specific interpretability techniques.

### UNIT-V: Model Evaluation and Selection (08 Hours)
- **Evaluation Metrics**: Classification metrics (Accuracy, Precision, Recall, F1, ROC-AUC), Regression metrics (MSE, MAE, R², Adjusted R²).
- **Cluster Validation**: External, internal, and relative validation measures.
- **Regression Assessment**: Hypothesis testing, cross-validation, model selection.
- **Hyperparameter Tuning**: Grid Search, Random Search, Bayesian Optimization, automated frameworks.

### UNIT-VI: Advanced Concepts and Applications (08 Hours)
- **Transfer Learning**: Transfer learning techniques, domain adaptation, and applications.
- **Meta-Learning**: Learning to learn, few-shot learning techniques.
- **Adversarial Machine Learning**: Adversarial attacks, defense mechanisms, robustness.
- **Ethics**: Fairness, Accountability, Transparency (FAT) in ML, social implications.
