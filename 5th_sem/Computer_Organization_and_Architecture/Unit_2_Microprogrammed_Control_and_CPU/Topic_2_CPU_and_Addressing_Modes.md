# Topic 2: CPU and Addressing Modes

- **General Register Organization**: Registers connected through multiplexers to ALU inputs.
- **Addressing Modes**:
  - *Immediate*: Value is in the instruction.
  - *Direct*: Address is in the instruction.
  - *Indirect*: Address in instruction points to memory holding actual address.
  - *Relative*: Offset added to Program Counter (PC).
