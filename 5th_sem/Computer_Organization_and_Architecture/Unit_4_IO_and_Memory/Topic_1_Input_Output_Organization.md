# Topic 1: Input-Output Organization

- **Asynchronous Transfer**: Handshaking (bi-directional signals) vs Strobe Control (unidirectional signal).
- **Transfer Modes**:
  - *Programmed I/O*: CPU polls device status constantly.
  - *Interrupt I/O*: Device alerts CPU when ready.
  - *DMA (Direct Memory Access)*: DMA controller takes bus control to transfer data directly between peripheral and memory.
